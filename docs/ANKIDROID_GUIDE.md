# AnkiDroid User Guide

Ready offline instructions for decks generated by Deutsch Lesson Cards.

Ordinary usage questions should be answered from this file without web search. Search only when the user explicitly asks for current version-specific UI verification.

## What is generated

One request such as «собери карточки из этого урока» produces one **deck / набор карточек** with many individual flashcards. In GitHub the deck is stored as `<name>.json` plus the ready `<name>.apkg` beside it.

Example:

`lesson-12.apkg`

It may contain 20, 30, or 50 flashcards.

## Recommended Android app

Use **AnkiDroid Flashcards**.

AnkiDroid owns spaced-repetition scheduling, due cards, review history, and progress/statistics.

## Import

1. Install AnkiDroid on Android.
2. Download the deck's `.apkg` from `lingua-cards` (or use the copy returned in chat).
3. Open it from Downloads/File Manager and choose AnkiDroid.
4. If Android does not offer that action, open AnkiDroid and use its import action to select the file.
5. Confirm import.
6. Open the imported deck.

The deck uses the short source name, lesson number, or date, for example `lesson-12` or `2026-09-29`.

Exact menu placement can vary by version; do not invent precise version-specific clicks unless verification is explicitly requested.

## Study

1. Open the deck.
2. Read the front.
3. Recall the German target before revealing.
4. Reveal the answer.
5. Grade recall with available buttons, typically Again / Hard / Good / Easy.
6. Return regularly for due reviews.

## Progress

Use AnkiDroid statistics/progress views for review activity, due counts, retention/statistical summaries, and deck progress exposed by the installed version.

## Optional sync

For multi-device use, sign in to AnkiWeb in AnkiDroid and sync.

## Later decks

A later lesson/topic/source can create another deck.

Before creation, Deutsch Lesson Cards checks the sharded dedupe registry. Vocabulary already introduced in an earlier deck is skipped, so the later deck normally contains only newly selected vocabulary.

The repository stores one deck as one JSON file with many flashcards. It does not create one file per word.
