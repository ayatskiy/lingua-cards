# Anki / AnkiDroid Fallback Guide

Anki is supported as an optional fallback. It is not generated by default.

Anki artifacts live under:

`apps/anki/<project-slug>/<deck-name>.apkg`

To get one:
- explicitly ask «сделай Anki-версию этого набора»; or
- use the format-conversion command.

Import the resulting APKG into Anki/AnkiDroid normally. Review scheduling and progress remain owned by Anki.

The canonical deck JSON stays application-neutral, so generating an Anki fallback does not duplicate or alter vocabulary.
